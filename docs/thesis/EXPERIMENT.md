## 3 实验二：典型接口响应时间（ms）

**方法**：每个接口用同一请求体，执行 **20 次**，去掉最高最低各 2 次后取平均（或直接用浏览器 Network 看单次也可，论文中注明「单次观测」）。

### 3.1 登录接口

| 方案 | 接口 URL | 平均耗时 (ms) | 备注 |
|------|-----------|---------------|------|
| 单体 | `POST http://localhost:8080/api/login` | | |
| 微服务 | `POST http://localhost:9000/api/login` | | 经网关多一跳 |

**命令示例（PowerShell 可改用循环）**：

```bash
curl.exe -w "\n%{time_total}s\n" -o NUL -s -X POST http://localhost:9000/api/login -H "Content-Type: application/json" -d "{\"username\":\"admin\",\"password\":\"你的密码\",\"role\":2}"
```
