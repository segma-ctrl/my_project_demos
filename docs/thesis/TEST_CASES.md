## 5 论文中的写法建议

在「系统测试」一章中可写：

1. 测试环境：CPU / 内存 / 操作系统、浏览器类型、网关与各服务版本号。  
2. 测试方法：**黑盒功能测试**，依据上表执行。  
3. 测试结论：共执行 *n* 条，通过 *m* 条，失败 *k* 条（若有失败，说明缺陷与修复情况）。

将本表精简为 **10 条左右** 放入正文，其余放附录即可。
